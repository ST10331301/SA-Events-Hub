# SA Events Hub

## App Description
A Kotlin Android application for discovering and managing events in South Africa.

## Features
- Browse local events
- Event details and registration
- User-friendly interface

## Installation
1. Clone this repository: `git clone https://github.com/RC_Student_Lab/SA-Events-Hub.git`
2. Open in Android Studio
3. Build and run the app

## Technology Stack
- Kotlin
- Android SDK
- Gradle Build System

## Development
This app demonstrates modern Android development practices with proper logging and code documentation.
